# WorldTV Support

WorldTV is an open-source project. Before reporting a problem, update to the latest available version, confirm that at least one playlist source is configured in Sources, and try refreshing the catalog from Settings.

## Get help

- For reproducible app defects, open a [GitHub issue](https://github.com/HerniRG/WorldTV/issues) with the platform, OS version, app version, expected result, and actual result.
- For security vulnerabilities, follow [SECURITY.md](SECURITY.md). Do not disclose a vulnerability in a public issue.
- For privacy questions, read [PRIVACY.md](PRIVACY.md) and use the issue tracker if the answer is not covered.
- For channel review or removal, use the dedicated [channel-removal form](https://github.com/HerniRG/WorldTV/issues/new?template=channel-removal.yml).

Do not post private stream tokens, personal information, crash logs containing sensitive data, or copyrighted broadcast recordings.

WorldTV cannot guarantee that a third-party stream remains online, works in every country, or is compatible with AVPlayer.

# Soporte de WorldTV

WorldTV es un proyecto de código abierto. Antes de comunicar un problema, actualiza a la última versión disponible, confirma que tienes al menos una fuente de lista configurada en Fuentes e intenta actualizar el catálogo desde Ajustes.

## Obtener ayuda

- Para errores reproducibles de la aplicación, abre una [incidencia en GitHub](https://github.com/HerniRG/WorldTV/issues) indicando plataforma, versión del sistema, versión de la aplicación, resultado esperado y resultado obtenido.
- Para vulnerabilidades de seguridad, sigue [SECURITY.md](SECURITY.md). No publiques vulnerabilidades en una incidencia pública.
- Para consultas de privacidad, lee [PRIVACY.md](PRIVACY.md) y utiliza el sistema de incidencias si no encuentras la respuesta.
- Para revisar o retirar un canal, utiliza el [formulario específico](https://github.com/HerniRG/WorldTV/issues/new?template=channel-removal.yml).

No publiques tokens privados de emisiones, información personal, registros con datos sensibles ni grabaciones de emisiones protegidas.

WorldTV no puede garantizar que una emisión externa siga disponible, funcione en todos los países o sea compatible con AVPlayer.
