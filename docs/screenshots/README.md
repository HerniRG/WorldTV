# Screenshot checklist

The approved App Icon and Apple TV Top Shelf artwork are now included. The checked-in Apple TV Home image is a real 1920×1080 simulator capture; the remaining store-facing captures are still pending.

Screenshots show the loaded app, so each capture run must configure at least one playlist source with channels whose names and logos can be shown. Capture with Spanish and English localizations where appropriate:

## Capture rules

- Use only channels whose logos and names can appear in repository documentation.
- Avoid including a broadcast frame or other copyrighted programme content.
- Show a clear focus state in the Apple TV Home image.
- Do not include account names, file paths, notifications, or other personal information.
- Keep raw PNG files in this directory and optimize them without changing visual fidelity.
- Update the main README as each approved image is added.
